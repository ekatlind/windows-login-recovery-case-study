# Windows 11 Login Recovery Case Study

## Overview

This repository documents my investigation and recovery process after a Windows 11 authentication issue prevented me from logging into my computer.

The goal was to restore access while preserving user data and exhausting non-destructive recovery methods before performing a clean reinstall.

This case study demonstrates structured troubleshooting, documentation, and problem-solving rather than software development.

- Windows 11 administration
- System troubleshooting
- Windows Recovery Environment (WinRE)
- Command-line diagnostics
